# AI Agent Contribution Guidelines

This document is an entry point for AI agents. The full guidelines are in the `.agent/` directory.

**First Action:** Read the contribution guidelines and project knowledge:
1. `.agent/AGENTS.md` — Workflow rules, git process, PR management
2. `.agent/project.md` — Project-specific technical knowledge (architecture, builds, deployment, testing, task management)
